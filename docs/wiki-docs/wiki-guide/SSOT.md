Single Source of Truth（单一事实来源）：每个概念有且仅有一处权威定义，其他地方通过【引用】指向它。

## 原则

- 一个概念只定义一次。在 wiki 中，定义方式见【词条】。
- 需要使用某个概念时，用【引用】而不是手动重写描述。
- 修改概念时，只改定义源头，所有引用处自动获得更新后的内容。

## 违反 SSOT 的表现

同一个概念在多处被手动描述（复制粘贴或各自措辞），没有使用 `【】` 引用。修改时只改了一处，其余处仍是旧描述。

## 修复方法

1. 为该概念创建【词条】文件（或文件内临时定义）
2. 将各处手动描述替换为 `【词条名】`【引用】

## 定位源头

```bash
# 查找词条的文件定义（文件名即词条名）
find wiki-docs/ -name "暴击率.md"

# 查找词条的内联定义
rg "【暴击率】[：:]" wiki-docs/

# 查找公式定义
rg "%%.* \[伤害\] .*%%" wiki-docs/
```
