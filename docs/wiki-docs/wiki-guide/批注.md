审校者对 wiki 文档的修改建议。每条批注关联一段选中的原文，附带审校者的评论。

## 存储

以 JSON 文件存储在 `wiki-docs/.annotations/` 目录下，每个文档对应一个文件。

## 字段

| 字段 | 类型 | 含义 |
|------|------|------|
| `id` | string | 批注唯一标识 |
| `selectedText` | string | 审校者选中的原文文本 |
| `comment` | string | 审校者的修改建议 |
| `anchorLine` | number \| null | 选区所在的源文件行号 |
| `status` | string | `open` 待处理 / `resolved` 已解决 / `rejected` 已驳回 |
| `updatedAt` | string | ISO 8601 时间戳，状态变更时更新 |

## 文件结构

```json
{
  "filePath": "心跳策略.md",
  "annotations": [
    {
      "id": "a1",
      "selectedText": "间隔 4.5 分钟",
      "comment": "确认这个数值",
      "anchorLine": 12,
      "status": "open"
    }
  ]
}
```

## 查询

```bash
# 列出所有 open 状态的批注
jq -r '
  .filePath as $f |
  .annotations[] | select(.status == "open") |
  "\($f) L\(.anchorLine // "?") | \"\(.selectedText)\" → \(.comment)"
' wiki-docs/.annotations/*.json
```
