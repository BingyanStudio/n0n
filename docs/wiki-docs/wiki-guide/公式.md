用 `%% %%` 包裹公式，系统自动高亮其中的计算值和设计值。

## 语法

```md
%% [伤害] = <攻击力> * (1 + <暴击率> * <暴击伤害>) %%
```

- `[xxx]` — 计算值/结果（蓝色加粗）
- `<xxx>` — 设计值/参数（紫色斜体）

## 示例

```md
## 伤害计算

%% [最终伤害] = <基础攻击> * [倍率] %%

其中：
%% [倍率] = 1 + <暴击率> * <暴击伤害> %%
```

## 常见问题

**Q: 公式没有高亮？**

- 确认用了 `%% %%` 包裹
- 计算值用 `[方括号]`，设计值用 `<尖括号>`
