不同项目有同名【词条】时，用 `scope` 隔离，避免冲突。

## 声明 scope

在文件开头的 frontmatter 中声明：

```md
---
scope: 游戏A
---

# NPC

游戏A 中的 NPC 定义...
```

同名词条在不同 scope 下互不干扰：

```
wiki-docs/
├── npc-a.md         → scope: 游戏A，词条「NPC」
└── npc-b.md         → scope: 游戏B，词条「NPC」
```

## 跨 scope 引用

用 `【scope/词条】` 显式【引用】其他 scope 的词条：

```md
---
scope: 游戏A
---

这是游戏A的文档。

【NPC】              # 自动引用 游戏A 的 NPC
【游戏B/NPC】        # 显式引用 游戏B 的 NPC
```

## 全局词条

不设置 `scope` 的词条是全局的，所有文件都能引用。

通用概念放在全局，项目特有的概念用 scope 隔离。
