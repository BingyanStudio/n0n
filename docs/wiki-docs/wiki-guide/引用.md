用**中文方括号** `【】` 引用已定义的【词条】：

```md
玩家使用【滑移】后，会触发【冲击伤害】。
```

## 效果

- 词条显示为链接样式
- 鼠标悬停显示定义卡片
- 卡片内的词条可以继续悬停

## 找不到词条时

系统会提示拼写相似的词条，帮你发现拼写错误。

## 引用优先级

当同名词条存在多个定义时，按以下顺序查找：

1. **文件内定义** — 当前文件中的临时定义
2. **当前 scope** — 与当前文件相同【区域隔离】的词条
3. **全局定义** — 没有设置 scope 的词条
4. **其他 scope** — 不会自动显示，需要显式引用
