# 上下文压缩 — 开发计划

> 关联词条：【压缩策略】

## 概述

根据【压缩策略】的分析结论，实现周期性上下文压缩功能。需与 Fairy 应用的 `view.ts` 跳变窗口机制协调。

## 要点

- 两种后端：原模型压缩（利用【提示词缓存】cache hit）/ 便宜模型压缩（全量输入但便宜）
- 最优触发间隔（r=0.15, 系统 30K, 步进 2.6K, 压缩到 5K, 隐性开销 $0.05~0.10）：约 8~15 步（上下文 56~74K）

## 实现清单

- [ ] 通用压缩接口（输入 `DomainMessage[]`，输出摘要 `DomainMessage`）
- [ ] 压缩后端选择逻辑
- [ ] 触发策略（固定间隔 / 上下文大小阈值 / 成本预估）
- [ ] 压缩质量保障
