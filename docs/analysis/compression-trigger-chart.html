每 N 步压缩一次，最优 N 在哪里？Opus 原地 vs 便宜模型

会话模型：系统 30K + 每步 +2.6K（2K in + 0.6K out），压缩到 5K 历史
每步可变成本：context × $0.50/MTok（cache read）
压缩成本 Opus：context × $0.50/MTok + 5K × $25/MTok
压缩成本 Cheap：r × (context × $5/MTok + 5K × $25/MTok)
隐性开销：每次压缩 + C_overhead（延迟 / 信息损失 / 打断对话流）
优化目标：avg = (∑ cache_read + compression + C_overhead) / N → min
