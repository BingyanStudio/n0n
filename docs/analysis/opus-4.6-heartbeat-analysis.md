# 命题 1 策略 A × Opus 4.6 — 心跳刷新甜蜜点分析

> 配套可视化：[opus-4.6-heartbeat-chart.html](./opus-4.6-heartbeat-chart.html)

## 背景

Anthropic prompt cache TTL 为 5 分钟。策略 A（心跳刷新）在接近 TTL 到期时发送轻量请求（`max_tokens=1`）刷新缓存前缀，使用户回来时直接 cache hit。

问题：心跳本身有成本，刷到什么时候该放弃？

## Opus 4.6 定价

| 项目 | 价格 |
|------|------|
| Input | $5 / MTok |
| Output | $25 / MTok |
| Cache Write | $6.25 / MTok |
| Cache Read | $0.50 / MTok |

## 缓存过期时的计费

缓存过期后用户回来，前缀带 `cache_control` 标记重新发送：
- **Input 处理**：$5/MTok（完整输入处理）
- **Cache Write**：$6.25/MTok（重建缓存）
- 合计 = $11.25/MTok

缓存命中时：
- **Cache Read**：$0.50/MTok

因此 miss 额外成本 = $5 + $6.25 - $0.50 = **$10.75/MTok**

## 核心推导

简化模型（纯线性）：

```
单次心跳成本     = prefix × $0.50/MTok     （cache read）
Cache miss 额外  = prefix × $10.75/MTok    （input + cache write - cache read）
盈亏平衡次数 N   = $10.75 / $0.50 = 21.5 次 ≈ 86 分钟
```

此时 prefix 在分子分母中线性出现，约掉了——盈亏平衡与前缀无关。

修正模型（加入固定开销）：

```
单次心跳成本     = prefix × $0.50/MTok + C_fixed
Cache miss 额外  = prefix × $10.75/MTok
盈亏平衡次数 N   = (prefix × 10.75) / (prefix × 0.50 + C_fixed)
```

C_fixed 打破线性对称：**前缀越小，固定开销占比越大，甜蜜点越早到来。**

以 C_fixed ≈ $0.005（~1000 非缓存 token）为例：

| 前缀 | 盈亏次数 | 盈亏时间（4min 间隔）|
|------|---------|---------------------|
| 10K  | 10.8 次 | ~43 min |
| 50K  | 17.9 次 | ~72 min |
| 100K | 19.5 次 | ~78 min |
| 200K | 20.5 次 | ~82 min |
| ∞    | 21.5 次 | ~86 min（理论极限）|

## 场景对照

| 场景 | 有心跳(额外) | 无心跳(额外) | 节省 |
|------|-------------|-------------|------|
| 离开 8min, 50K 前缀 | $0.050 | $0.538 | 91% |
| 离开 30min, 100K 前缀 | $0.350 | $1.075 | 67% |
| 离开 1h, 100K 前缀 | $0.750 | $1.075 | 30% |
| 离开 2h, 100K 前缀 | $1.501 | $1.075 | -40%（亏损） |
| 离开 1h, 200K 前缀 | $1.500 | $2.150 | 30% |

## 实施建议

- **fairy 模式**：启用心跳，上限 20 次（~80min），覆盖绝大多数"暂时离开"场景
- **code 模式**：不需要——`MAX_TIMEOUT_S = 240` 已在 TTL 内
- 超过 80min 未归，接受 cache miss（用户大概率已切换上下文）

## 与其他模型对比

| 模型 | Cache Read | Input | 理论 N |
|------|-----------|-------|--------|
| Opus 4.6 | $0.50 | $5.00 | 21.5 |
| Sonnet 4 | $0.30 | $3.00 | 21.5 |
| Haiku 3.5 | $0.03 | $0.25 | ~21.6 |

Anthropic 各模型的 cache read / input 比例保持一致（~1:10），盈亏平衡次数几乎相同。选择哪个模型不影响策略 A 的时间窗口，只影响绝对金额。
