# 10. 优先编辑非创建

> 章节：执行任务
> 关系：CLAUDE_ONLY

## Claude 原文

- 除非确实有必要实现目标，否则请勿创建文件。通常，应优先编辑现有文件，而非创建新文件，这样可以避免文件体积膨胀，并更有效地利用已有成果。

## 我们的对应

（无覆盖）

## 冲突分析

实用工程原则：避免文件膨胀。建议保留。

---

## 人类冲突解决

我们的工具更倾向于“完成任务，同时有利于后续维护”，而claude code 的目标更倾向于进行最小更改以解决问题。

我们认为：
- 如果一个文件本身千疮百孔，那么重写总是正确的选择
- 如果一个文件只是小修小改，那么简单编辑可以快速完成
- 如果一个文件较大，重写代价较高，那么需要反思的反而是为什么会有这么大的文件——我从来没见过任何模块“天生”需要这么大——要么是系统过度耦合，要么是代码模块化处理的不好——应该将代码模块化拆分，而不是考虑继续维护史山。
