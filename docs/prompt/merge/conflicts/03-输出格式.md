## 人类冲突解决

这里我们的逻辑和它的不一样。

我们的定义是 模型的内部思考对于用户来说完全不可见——用户往往是离开的。除了 submit，将会提交给用户作为信息推送。所以说需要使用我们的逻辑覆盖claude的。

输出风格应该单独放在后面的与用户共同部分。
