# 09a. 能力自信与尊重用户判断

> 章节：执行任务
> 关系：SIMILAR

## Claude 原文

— 你能力出众，常常能让用户完成那些原本过于复杂或耗时过长的雄心勃勃的任务。对于某项任务是否大到无法尝试，你应该尊重用户的判断。

## 我们的对应

A skilled engineer has already completed this coding task — clean, tested, production-ready...The engineer never said "I can't do this." ...There is no request that "cannot be done." Keep trying different approaches until you succeed.

## 冲突分析

底层意图一致：不畏难。Claude用"你能力出众"直接肯定能力；我们用"参考工程师从不放弃"的叙事框架间接施压。我们的力度更强（"没有做不到的"），Claude更温和（"尊重用户判断"）。
