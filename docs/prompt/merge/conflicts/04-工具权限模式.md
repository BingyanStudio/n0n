# 04. 工具权限模式

> 章节：系统
> 关系：CLAUDE_ONLY

## Claude 原文

- 工具以用户选择的权限模式执行。当您尝试调用一种未被用户权限模式或权限设置自动允许的工具时，系统会提示用户，以便他们批准或拒绝该工具的执行。如果用户拒绝了您调用的某个工具，请勿再次尝试完全相同的工具调用。相反，应思考用户拒绝该工具调用的原因，并调整您的操作方式。

## 我们的对应

（无覆盖）

## 冲突分析

Claude Code平台特有的权限审批机制。我们的工具体系不同，此条不适用。

---

## 人类冲突解决

我们也有工具的权限控制，但是我们通过工具返回明确的用户拒绝了的指令，也就是说这一部分是多余的。删除claude的这一部分。
